> 작성자 검토 전

지금까지 생성모델의 기본적인 개념들을 살펴봤다.

생성모델의 목표는 실제 데이터 분포 \(p_{\mathrm{data}}\)를 근사하는 것이었다. 이를 위해 Likelihood를 최대화하거나, KL Divergence와 같은 척도를 이용해 두 분포의 차이를 줄이는 방법을 배웠다.

또한 모델에 따라 확률밀도를 계산하는 방법과 새로운 데이터를 생성하는 방법이 달라질 수 있다는 것도 확인했다.

그렇다면 실제 생성모델들은 어떤 방식으로 만들어질까?

생성모델에는 여러 종류가 있지만, 모두 같은 방법으로 확률분포를 표현하는 것은 아니다. 어떤 모델은 데이터를 순서대로 생성하고, 어떤 모델은 잠재변수를 이용하며, 또 다른 모델은 확률밀도의 기울기만을 학습하기도 한다.

이번 절에서는 대표적인 생성모델들을 간단히 살펴보고, 각 모델이 어떤 특징을 갖는지 정리해보자.

## Autoregressive Model (AR)

먼저 데이터를 여러 변수로 이루어진 벡터라고 생각해보자.

\[
x=(x_1,x_2,\ldots,x_d).
\]

여기서 \(x_i\)는 데이터의 \(i\)번째 변수다. 예를 들어 이미지라면 각 픽셀의 값이 될 수 있고, 문장이라면 각 위치의 토큰이 될 수도 있다.

이때 결합확률분포는 확률의 Chain Rule에 따라 다음과 같이 분해할 수 있다.

\[
\boxed{
p_\theta(x)
=
\prod_{i=1}^{d}
p_\theta(x_i\mid x_{<i})
}
\]

여기서 \(x_{<i}=(x_1,\ldots,x_{i-1})\)는 \(i\)번째 변수보다 앞에 있는 변수들을 의미한다.

예를 들어 변수가 세 개라면

\[
p_\theta(x_1,x_2,x_3)
=
p_\theta(x_1)
p_\theta(x_2\mid x_1)
p_\theta(x_3\mid x_1,x_2)
\]

가 된다.

Autoregressive Model은 이러한 분해를 이용해 각 조건부분포를 학습한다.

그렇다면 Sampling은 어떻게 할까?

먼저 \(x_1\)을 생성하고, 그 값을 이용해 \(x_2\)를 생성한다. 다음에는 앞서 생성한 \(x_1,x_2\)를 이용해 \(x_3\)를 생성하는 식이다.

즉, **앞에서 생성한 값을 조건으로 다음 값을 하나씩 생성하는 모델**이다.

이 방법의 장점은 각 조건부분포를 계산할 수 있다면 전체 데이터의 Log-Likelihood도 계산할 수 있다는 것이다.

\[
\log p_\theta(x)
=
\sum_{i=1}^{d}\log p_\theta(x_i\mid x_{<i}).
\]

반면 Sampling할 때는 앞의 결과가 있어야 다음 값을 생성할 수 있으므로 일반적으로 순차적인 계산이 필요하다.

따라서 Autoregressive Model은 **Likelihood 계산은 비교적 직접적이지만, Sampling은 순차적으로 이루어진다**는 특징이 있다.

## Variational Autoencoder (VAE)

이번에는 데이터를 순서대로 생성하는 대신, 잠재변수(Latent Variable)를 이용하는 방법을 생각해보자.

1.11절에서 배운 잠재변수 모델에서는 먼저 \(z\)를 뽑고, 이를 조건으로 데이터 \(x\)를 생성했다.

\[
\boxed{
\begin{aligned}
z&\sim p_0(z),\\
x\mid z&\sim p_\theta(x\mid z).
\end{aligned}
}
\]

Variational Autoencoder(VAE)는 이러한 잠재변수 모델의 대표적인 예다.

예를 들어 손글씨 숫자 이미지를 생성한다고 생각해보자.

먼저 잠재변수 \(z\)를 뽑고, 이를 이용해 숫자 이미지의 확률분포를 만든 다음 실제 이미지 \(x\)를 생성할 수 있다.

VAE에서는 잠재변수 \(z\)를 관측하지 않는다. 따라서 어떤 이미지 \(x\)의 확률밀도를 계산하려면 가능한 모든 \(z\)를 고려해야 한다.

\[
\boxed{
p_\theta(x)
=
\int p_0(z)p_\theta(x\mid z)\,\mathrm dz
}
\]

그런데 이 적분은 계산하기 어려울 수 있다.

Sampling할 때는 \(z\)를 하나 뽑으면 되지만, \(p_\theta(x)\)를 계산하려면 가능한 잠재변수 전체에 대해 적분해야 하기 때문이다.

VAE는 이 문제를 다루기 위해 Encoder 쪽에 다음과 같은 분포를 도입한다.

\[
q_\phi(z\mid x).
\]

이 분포는 관측값 \(x\)가 주어졌을 때 잠재변수 \(z\)의 사후분포 \(p_\theta(z\mid x)\)를 근사하는 **Approximate Posterior**다.

이를 이용하면 직접 계산하기 어려운 Log-Likelihood 대신 ELBO(Evidence Lower Bound)라는 계산 가능한 하한을 구성해 학습할 수 있다.

ELBO의 자세한 유도는 이후 VAE를 공부하면서 다룰 것이다.

지금은 VAE가 **잠재변수를 이용해 데이터를 생성하고, 계산하기 어려운 Likelihood를 근사적인 방법으로 다루는 모델**이라는 점을 이해하면 충분하다.

## Generative Adversarial Network (GAN)

앞의 VAE는 확률분포를 수학적으로 정의하고, 그 Likelihood를 다루기 위해 근사적인 방법을 사용했다.

그런데 꼭 Likelihood를 계산해야만 생성모델을 학습할 수 있을까?

GAN은 조금 다른 접근을 사용한다.

먼저 간단한 분포 \(p_0\)에서 잠재변수 \(z\)를 뽑고, Generator \(G_\theta\)에 입력한다.

\[
\boxed{
z\sim p_0,\qquad x=G_\theta(z)
}
\]

Generator는 잠재변수를 새로운 데이터로 변환한다.

그런데 Generator가 만든 데이터가 실제 데이터와 비슷한지는 어떻게 판단할까?

GAN에서는 이를 위해 **Discriminator**라는 모델을 함께 사용한다.

Discriminator는 입력받은 데이터가 실제 데이터인지, Generator가 생성한 데이터인지 구분하도록 학습한다.

반대로 Generator는 Discriminator가 생성된 데이터를 실제 데이터와 구분하기 어렵도록 학습한다.

이렇게 두 모델이 서로 경쟁하는 과정에서 Generator의 성능을 개선한다.

GAN의 특징은 Generator가 표현하는 분포의 밀도함수 \(p_\theta(x)\)를 직접 계산할 필요가 없다는 것이다.

Sampling은 간단하다.

\[
z\sim p_0
\quad\longrightarrow\quad
G_\theta(z)
\quad\longrightarrow\quad
x.
\]

하지만 주어진 \(x\)의 확률밀도 \(p_\theta(x)\)를 계산하는 것은 일반적으로 어렵다.

따라서 GAN은 **Sampling 과정을 중심으로 분포를 정의하는 Implicit Generative Model**의 대표적인 예다.

## Energy-based Model과 Score-based Model

이번에는 확률분포를 조금 다른 방식으로 표현하는 모델들을 살펴보자.

### Energy-based Model (EBM)

Energy-based Model은 각 데이터 \(x\)에 Energy라는 값을 부여한다.

이 값을 \(E_\theta(x)\)라고 하면, 분포를 다음과 같이 정의할 수 있다.

\[
\boxed{
p_\theta(x)
=
\frac{\exp(-E_\theta(x))}{Z_\theta}
}
\]

여기서 \(Z_\theta\)는 정규화 상수다.

\[
Z_\theta
=
\int\exp(-E_\theta(x))\,\mathrm dx.
\]

Energy가 낮은 위치일수록 \(\exp(-E_\theta(x))\)가 커지므로, 상대적으로 높은 확률밀도가 부여된다.

그런데 문제는 \(Z_\theta\)를 계산하기 어렵다는 것이다.

고차원 데이터에서는 모든 가능한 \(x\)에 대해 적분해야 하므로 정규화 상수를 직접 계산하는 것이 현실적으로 어려울 수 있다.

따라서 Energy Function은 계산할 수 있어도, 정확한 확률밀도 \(p_\theta(x)\)는 계산하기 어려울 수 있다.

이 모델은 1.10절에서 살펴본 것처럼 분포를 수식으로 명시하는 Explicit Model이지만, Density Evaluation이 반드시 쉬운 것은 아니다.

### Score-based Model

Score-based Model은 확률밀도 자체보다는 그 밀도의 기울기에 주목한다.

1.8절에서 정의한 Score Function을 다시 생각해보자.

\[
s_p(x)=\nabla_x\log p(x).
\]

이 함수는 현재 위치 \(x\)에서 로그밀도가 어느 방향으로 가장 빠르게 증가하는지를 알려준다.

Score-based Model은 신경망 \(s_\theta(x)\)을 이용해 실제 데이터 분포의 Score Function을 근사하는 것을 목표로 한다.

\[
\boxed{
s_\theta(x)
\approx
\nabla_x\log p_{\mathrm{data}}(x)
}
\]

이렇게 하면 확률밀도의 정확한 값 대신, 데이터 공간의 각 위치에서 밀도가 변하는 방향에 관한 정보를 학습할 수 있다.

물론 Score Function을 알게 되었다고 해서 곧바로 새로운 데이터를 생성할 수 있는 것은 아니다. 실제 Sampling을 위해서는 학습한 Score를 활용하는 별도의 생성 과정이 필요하다.

지금은 Score-based Model이 **확률밀도 자체가 아니라 Log-Density의 국소적인 변화 정보를 활용한다**는 점에 주목하자.

이 접근은 이후 Diffusion Model과 Score-based Generative Model을 이해하는 데 중요한 기반이 된다.

## Normalizing Flow

마지막으로 Normalizing Flow를 살펴보자.

1.11절에서는 간단한 확률분포에서 잠재변수 \(z\)를 뽑고, 함수 \(T_\theta\)를 이용해 데이터 \(x\)로 변환하는 방법을 배웠다.

\[
z\sim p_0,\qquad x=T_\theta(z).
\]

Normalizing Flow는 이러한 변환을 이용하는 생성모델이다.

여기서 중요한 조건은 \(T_\theta\)가 가역적(Invertible)이라는 것이다.

즉, \(z\)에서 \(x\)를 계산할 수 있을 뿐 아니라, \(x\)가 주어졌을 때 원래의 \(z\)도 구할 수 있어야 한다.

이 조건을 만족하면 Change of Variables 공식을 이용해 확률밀도를 계산할 수 있다.

\[
\boxed{
p_\theta(x)
=
p_0(T_\theta^{-1}(x))
\left|\det J_{T_\theta^{-1}}(x)\right|
}
\]

여기서 Jacobian Determinant는 변환 과정에서 부피가 얼마나 변하는지를 반영한다.

따라서 Normalizing Flow에서는 두 가지 연산을 모두 수행할 수 있다.

Sampling할 때는 간단한 기저분포에서 \(z\)를 뽑고 \(T_\theta(z)\)를 계산하면 된다.

Density Evaluation을 할 때는 주어진 \(x\)에 역변환을 적용한 다음 Jacobian Determinant를 이용해 밀도를 계산한다.

물론 이를 효율적으로 수행하려면 역변환과 Jacobian Determinant가 계산하기 쉬운 구조로 \(T_\theta\)를 설계해야 한다.

Normalizing Flow는 이러한 조건을 만족하는 변환을 사용함으로써 **데이터를 생성하는 과정과 확률밀도를 계산하는 과정을 모두 다룰 수 있도록 만든 모델**이다.

## 생성모델의 특징 비교

지금까지 살펴본 생성모델들을 정리해보자.

| 모델 | 분포를 표현하는 방법 | 주요 특징 |
|---|---|---|
| Autoregressive | 조건부분포의 곱 | Likelihood 계산이 직접적이지만 Sampling은 순차적 |
| VAE | 잠재변수와 조건부분포 | Sampling은 비교적 쉽지만 Marginal Likelihood 계산은 어려울 수 있음 |
| GAN | Generator의 변환 | Sampling이 직접적이며 Density Evaluation은 일반적으로 어려움 |
| Energy-based | Energy Function | 정규화 상수 계산이 어려울 수 있음 |
| Score-based | Log-Density의 Gradient | 밀도 자체보다 국소적인 변화 정보를 학습 |
| Normalizing Flow | 가역적인 변수변환 | Sampling과 Density Evaluation을 모두 다룰 수 있음 |

이 표는 각 모델 계열의 대표적인 특징을 정리한 것이다. 실제 계산 비용이나 Sampling의 효율은 모델의 구체적인 구조에 따라 달라질 수 있다.

표를 보면 각 생성모델이 서로 다른 방식으로 확률분포를 표현한다는 것을 알 수 있다.

어떤 모델은 Likelihood 계산을 직접 다루기 쉽도록 설계되어 있고, 어떤 모델은 새로운 데이터를 생성하는 과정을 중심으로 만들어져 있다. 또 어떤 모델은 확률밀도 전체 대신 Score Function과 같은 정보를 활용한다.

그렇다고 어느 한 모델이 항상 다른 모델보다 좋은 것은 아니다.

실제 생성모델을 선택할 때는 데이터의 특성과 학습 목적에 따라 어떤 연산이 필요한지, 그 연산을 얼마나 효율적으로 수행할 수 있는지를 함께 고려해야 한다.

이 개념들은 이후 등장하는 생성모델들을 이해하는 데 공통적인 기초가 된다.

앞으로 새로운 모델을 공부할 때는 다음 질문을 떠올려보면 좋겠다.

**이 모델은 어떤 방식으로 확률분포를 표현하고, 그 분포를 학습하거나 새로운 데이터를 생성하기 위해 어떤 방법을 사용하는가?**

모델의 구조는 서로 다르지만, 결국 모두 실제 데이터의 분포를 학습하고 활용하려는 서로 다른 접근이라는 점에서 연결된다.
