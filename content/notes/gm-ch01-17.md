앞 절에서는 실제 데이터 분포와 모델 분포의 차이를 Forward KL로 측정하는 방법을 살펴봤다.

그런데 KL Divergence에는 조금 특이한 성질이 있다. 두 분포의 순서를 바꾸면 값도 달라진다는 것이다.

단순히 수식에 들어가는 순서만 바뀌는 것처럼 보이지만, 실제로는 **모델이 어떤 분포를 학습하게 되는지에도 영향을 줄 수 있다.**

이번 절에서는 그 이유를 살펴보자.

## Reverse KL — 분포의 순서를 바꾸면?

1.6절에서 정의한 Forward KL은 다음과 같다.

\[
D_{\mathrm{KL}}(p_{\mathrm{data}}\|p_\theta)
=
\mathbb E_{x\sim p_{\mathrm{data}}}
\left[
\log\frac{p_{\mathrm{data}}(x)}{p_\theta(x)}
\right].
\]

여기서는 실제 데이터 분포 \(p_{\mathrm{data}}\)를 기준으로 기댓값을 계산한다.

반대로 두 분포의 순서를 바꾸면 어떻게 될까?

\[
\boxed{
D_{\mathrm{KL}}(p_\theta\|p_{\mathrm{data}})
=
\mathbb E_{x\sim p_\theta}
\left[
\log\frac{p_\theta(x)}{p_{\mathrm{data}}(x)}
\right]
}
\]

이를 **Reverse KL**이라고 한다.

두 식의 차이는 기댓값 아래에 있는 분포를 보면 알 수 있다.

Forward KL에서는 실제 데이터 분포에서 자주 나타나는 값들이 비교에 큰 비중으로 반영된다. 반면 Reverse KL에서는 모델이 자주 생성하는 값들이 큰 비중으로 반영된다.

이 차이가 왜 중요할까?

예를 들어 실제 데이터가 어떤 영역에서 자주 관측되는데, 모델은 그 영역에서 거의 데이터를 생성하지 않는다고 하자.

Forward KL에서는 그 영역이 실제 데이터 분포에서 차지하는 비중이 크기 때문에 모델에 불리하게 작용한다.

하지만 Reverse KL에서는 모델이 그 영역에 거의 확률을 부여하지 않으므로, 해당 영역이 평균에 미치는 비중도 작아진다.

반대로 모델이 자주 생성하는 영역에서 실제 데이터의 밀도가 매우 낮다면 Reverse KL에서는 그 차이가 중요해진다.

즉, **Forward KL과 Reverse KL은 같은 두 분포를 비교하더라도 서로 다른 영역에 주목한다.**

### Remark 1.7.1 — 확률이 0인 영역

이 차이는 어떤 영역의 확률이 정확히 0인 경우에 더욱 분명해진다.

두 확률분포 \(P,Q\)와 어떤 영역 \(A\)를 생각해보자.

\(P\)에서는 \(A\)에 속하는 값이 나올 수 있지만, \(Q\)에서는 절대로 나올 수 없다고 하자.

\[
P(A)>0,\qquad Q(A)=0.
\]

이 경우

\[
\boxed{
D_{\mathrm{KL}}(P\|Q)=\infty
}
\]

가 된다.

첫 번째 분포에서는 실제로 일어날 수 있는 일을 두 번째 분포에서는 불가능하다고 판단한 것이다. KL Divergence는 이러한 차이를 무한대로 반영한다.

따라서 Forward KL이 유한하려면 실제 데이터가 나올 수 있는 영역을 모델이 완전히 빠뜨려서는 안 된다.

반대로 Reverse KL이 유한하려면 모델이 생성할 수 있는 영역을 실제 데이터 분포가 완전히 배제해서는 안 된다.

수학적으로 \(D_{\mathrm{KL}}(P\|Q)\)가 유한하려면 \(P\ll Q\)라는 조건이 필요하다. 이는 \(Q\)가 확률 0을 부여하는 모든 집합에 \(P\)도 확률 0을 부여해야 한다는 뜻이다.

이러한 차이가 실제 모델에서는 어떤 결과를 만드는지 살펴보자.

## Example 1.7.2 — 두 개의 봉우리를 하나의 정규분포로 표현하기

실제 데이터가 두 군데에 몰려 있는 상황을 생각해보자.

예를 들어 데이터의 절반은 \(-3\) 근처에, 나머지 절반은 \(3\) 근처에 분포한다고 하자.

이를 두 정규분포의 혼합으로 표현할 수 있다.

\[
\boxed{
p_{\mathrm{data}}(x)
=
\frac12\mathcal N(x;-3,1)
+
\frac12\mathcal N(x;3,1)
}
\]

여기서 \(\mathcal N(x;\mu,\sigma^2)\)는 평균이 \(\mu\), 분산이 \(\sigma^2\)인 정규분포의 밀도함수다.

이 분포의 그래프를 그리면 \(-3\)과 \(3\) 근처에 각각 봉우리가 나타난다. 이렇게 확률밀도가 주변보다 높은 봉우리를 **Mode**라고 부른다.

그런데 우리가 사용하는 모델은 하나의 정규분포뿐이라고 하자.

\[
p_\theta(x)=\mathcal N(x;\mu,\sigma^2).
\]

평균과 분산은 자유롭게 조절할 수 있지만, 정규분포 하나로는 두 개의 봉우리를 만들 수 없다.

그렇다면 모델은 어떤 모양을 선택해야 할까?

한 가지 방법은 분산을 크게 만들어 두 봉우리를 모두 넓게 포함하는 것이다. 반대로 한쪽 봉우리 근처에 집중하는 방법도 있다.

어느 쪽이 더 유리한지는 KL Divergence의 방향에 따라 달라질 수 있다.

### Forward KL — Mode Covering

먼저 Forward KL을 최소화한다고 하자.

\[
\underset{\theta}{\arg\min}\,
D_{\mathrm{KL}}(p_{\mathrm{data}}\|p_\theta).
\]

이 경우에는 실제 데이터 분포를 기준으로 모델을 평가한다.

만약 모델이 \(-3\) 근처에만 집중한다면 어떻게 될까?

실제 데이터의 절반은 \(3\) 근처에서도 나타난다. 그런데 모델이 이 영역에 매우 작은 밀도를 부여하면, 해당 데이터들의 Log-Likelihood가 낮아진다.

따라서 한쪽 봉우리에만 집중하는 것은 불리하다.

이 문제를 줄이려면 정규분포의 분산을 크게 만들어 두 봉우리를 모두 포함하는 방법을 선택할 수 있다.

실제로 이 예에서 Forward KL을 최소화하는 정규분포는

\[
p_{\theta^*}(x)=\mathcal N(x;0,10)
\]

이다. 실제 혼합분포의 평균이 0이고 분산이 10이므로, 모델도 그 평균과 분산에 맞춰진다.

물론 이렇게 하면 두 봉우리 사이에도 상당한 밀도를 부여하게 된다. 실제 데이터는 가운데 영역에서 드물게 나타나므로 완벽한 근사는 아니다.

그럼에도 한쪽 봉우리를 거의 놓치는 것보다는 양쪽을 넓게 포함하는 편이 Forward KL을 줄이는 데 유리하다.

이처럼 여러 Mode를 두루 포함하려는 경향을 **Mode Covering**이라고 한다.

### Reverse KL — Mode Seeking

이번에는 Reverse KL을 최소화해보자.

\[
\underset{\theta}{\arg\min}\,
D_{\mathrm{KL}}(p_\theta\|p_{\mathrm{data}}).
\]

이번에는 모델 분포를 기준으로 기댓값을 계산한다.

앞에서처럼 분산을 크게 만들어 두 봉우리를 모두 포함한다고 하자. 그러면 모델은 \(-3\)과 \(3\) 근처뿐 아니라 그 사이인 \(0\) 근처에서도 데이터를 생성하게 된다.

그런데 실제 데이터 분포에서 \(0\) 근처의 밀도는 매우 낮다.

즉, 모델이 비교적 자주 생성하는 값이 실제 분포에서는 거의 나타나지 않는 것이다. Reverse KL에서는 이러한 영역이 불리하게 작용한다.

그렇다면 모델을 한쪽 봉우리 근처에 집중시키는 것은 어떨까?

예를 들어 \(-3\) 근처에만 밀도를 집중시키면 모델이 생성하는 값들은 대부분 실제 데이터에서도 밀도가 높은 영역에 놓이게 된다.

물론 \(3\) 근처의 데이터를 제대로 표현하지 못한다는 문제가 남아 있다. 하지만 모델이 그 영역에 거의 확률을 부여하지 않으므로, 그 차이가 Reverse KL의 기댓값에 반영되는 비중은 상대적으로 작다.

따라서 두 봉우리가 충분히 떨어져 있다면, Reverse KL에서는 한쪽 봉우리 근처에 집중하는 분포가 더 유리할 수 있다.

이처럼 여러 Mode 중 일부에 집중하려는 경향을 **Mode Seeking**이라고 한다.

이 예에서는 실제 분포가 좌우 대칭이므로 왼쪽과 오른쪽에 집중하는 두 해가 대칭적으로 나타날 수 있다.

여기서 두 방향의 차이를 정리할 수 있다.

- **Forward KL:** 실제 데이터가 나타나는 영역을 놓치지 않으려 하므로 여러 Mode를 넓게 포함하는 경향이 있다.
- **Reverse KL:** 실제 데이터의 밀도가 낮은 영역에서 값을 생성하는 것을 피하려 하므로 특정 Mode에 집중하는 경향이 있다.

### Remark 1.7.3 — 항상 이런 결과가 나올까?

Mode Covering과 Mode Seeking이 모든 상황에서 반드시 나타나는 것은 아니다.

앞의 예에서 두 방법의 차이가 뚜렷했던 이유는 실제 데이터 분포에는 봉우리가 두 개 있지만, 모델은 정규분포 하나만 사용할 수 있었기 때문이다.

만약 모델이 실제 분포를 정확하게 표현할 수 있다면 어떻게 될까?

\[
p_\theta=p_{\mathrm{data}}
\]

일 때는

\[
\begin{aligned}
D_{\mathrm{KL}}(p_{\mathrm{data}}\|p_\theta)&=0,\\[4pt]
D_{\mathrm{KL}}(p_\theta\|p_{\mathrm{data}})&=0
\end{aligned}
\]

이므로 두 방향 모두 같은 분포에서 최솟값을 얻는다.

결국 Mode Covering과 Mode Seeking은 **모델이 실제 분포를 정확하게 표현할 수 없을 때, 두 KL이 어떤 차이를 더 크게 반영하는지**를 설명하는 경향이다.

또한 두 봉우리가 충분히 떨어져 있지 않다면 Reverse KL에서도 하나의 넓은 분포로 양쪽을 포함하는 편이 더 유리할 수 있다.

## Example 1.7.4 — KL의 방향에 따라 값이 달라지는 경우

마지막으로 간단한 이산분포를 이용해 KL의 비대칭성을 직접 계산해보자.

세 가지 값 \(x_1,x_2,x_3\)이 나올 수 있다고 하자. 두 확률분포 \(P,Q\)를 다음과 같이 정의한다.

\[
\begin{aligned}
P&=\left(\frac12,\frac12,0\right),\\[4pt]
Q&=\left(\frac12,\frac14,\frac14\right).
\end{aligned}
\]

즉, 각 값이 나올 확률은 다음과 같다.

| | \(x_1\) | \(x_2\) | \(x_3\) |
|---|---|---|---|
| \(P\) | \(1/2\) | \(1/2\) | \(0\) |
| \(Q\) | \(1/2\) | \(1/4\) | \(1/4\) |

두 분포를 비교하면 \(P\)에서는 \(x_3\)가 절대로 나오지 않지만, \(Q\)에서는 \(1/4\)의 확률로 나온다는 차이가 있다.

먼저 \(P\)를 기준으로 KL Divergence를 계산하자.

이산분포에서는 기댓값을 적분이 아니라 합으로 계산한다.

\[
\begin{aligned}
D_{\mathrm{KL}}(P\|Q)
&=\sum_{i=1}^{3}
P(x_i)\log\frac{P(x_i)}{Q(x_i)}\\[4pt]
&=\frac12\log1
+\frac12\log2
+0\\[4pt]
&=\frac12\log2.
\end{aligned}
\]

첫 번째 값은 두 분포에서 확률이 같으므로 로그비율이 0이다.

세 번째 값은 \(P(x_3)=0\)이므로 기댓값에 기여하지 않는다. 여기서는 \(0\log(0/q)=0\;(q>0)\)이라는 관례를 사용한다.

따라서 KL Divergence는 유한한 값을 갖는다.

이번에는 순서를 바꾸어보자.

\[
D_{\mathrm{KL}}(Q\|P)
=
\sum_{i=1}^{3}
Q(x_i)\log\frac{Q(x_i)}{P(x_i)}.
\]

여기서는 \(Q\)가 기준이 된다.

그런데 \(Q\)에서는 \(x_3\)가 \(1/4\)의 확률로 나온다. 반면 \(P\)에서는 \(x_3\)가 나올 확률이 정확히 0이다.

따라서

\[
\boxed{
D_{\mathrm{KL}}(Q\|P)=\infty
}
\]

가 된다.

앞에서는 계산에 영향을 주지 않았던 \(x_3\)가, 분포의 순서를 바꾸자 KL Divergence를 무한대로 만든 것이다.

두 분포 자체는 전혀 바뀌지 않았다. 단지 **어느 분포를 기준으로 비교하는지만 바뀌었을 뿐**이다.

이것이 KL Divergence의 방향을 구분해야 하는 이유다.

---

마지막으로 실제 학습에서의 차이도 생각해볼 필요가 있다.

1.6절에서 Forward KL을 MLE와 연결할 수 있었던 것은 실제 데이터 분포의 기댓값을 관측 표본의 평균으로 근사할 수 있었기 때문이다.

반면 Reverse KL은 모델 분포에서 기댓값을 계산한다.

모델에서 샘플을 생성할 수 있더라도, 그 샘플에서 실제 데이터 분포의 밀도 \(p_{\mathrm{data}}(x)\)를 알아야 Reverse KL을 직접 계산할 수 있다.

따라서 실제 데이터 분포의 밀도를 모르는 상황에서는 단순히 관측 데이터의 Log-Likelihood를 평균 내는 방식으로 Reverse KL을 계산할 수 없다.

Forward KL과 Reverse KL은 수식에서 분포의 순서만 다르지만, **모델이 어떤 영역을 중요하게 평가하는지뿐 아니라 실제 목적함수를 계산하는 방법에도 차이가 생긴다.**
