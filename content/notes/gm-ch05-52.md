# 5.2 Exact Likelihood

5.1절에서는 복잡한 결합확률분포를 여러 조건부분포의 곱으로 표현하는 방법을 배웠다.

\[
p_\theta(x)
=\prod_{i=1}^{D}p_\theta(x_i\mid x_{<i}).
\]

Autoregressive Model은 이 조건부분포들을 신경망 등의 함수로 표현한다.

그런데 이렇게 분포를 정의하면 어떤 장점이 있을까?

가장 중요한 특징 중 하나는 **주어진 데이터의 Likelihood를 정확하게 계산할 수 있다는 것**이다.

이번 절에서는 이 성질을 살펴보고, Autoregressive Model을 실제로 학습할 때 사용하는 Loss Function까지 연결해보자.

## 1. Exact Log-Likelihood

먼저 데이터 하나가 다음과 같이 주어졌다고 하자.

\[
x=(x_1,x_2,\ldots,x_D).
\]

우리가 알고 싶은 것은 모델이 이 데이터에 부여하는 확률 \(p_\theta(x)\)이다.

5.1절에서 배운 Chain Rule을 적용하면

\[
p_\theta(x)
=\prod_{i=1}^{D}p_\theta(x_i\mid x_{<i})
\]

이고, 양변에 로그를 취하면 다음과 같다.

\[
\boxed{
\log p_\theta(x)
=\sum_{i=1}^{D}\log p_\theta(x_i\mid x_{<i})
}
\]

여러 조건부확률의 곱이 로그를 취하면서 합으로 바뀌었다.

이 식이 중요한 이유는, 각 조건부분포만 계산할 수 있다면 전체 데이터의 Log-Likelihood도 계산할 수 있기 때문이다.

### 간단한 예시

세 개의 이진변수로 이루어진 데이터가 있다고 하자.

\[
x=(1,0,1).
\]

이 데이터의 결합확률은

\[
\begin{aligned}
p_\theta(1,0,1)
&=p_\theta(x_1=1)p_\theta(x_2=0\mid x_1=1)\\
&\quad\cdot p_\theta(x_3=1\mid x_1=1,x_2=0)
\end{aligned}
\]

이다.

이제 모델이 각 조건부확률을 다음과 같이 계산했다고 하자.

\[
\begin{aligned}
p_\theta(x_1=1)&=0.8,\\
p_\theta(x_2=0\mid x_1=1)&=0.7,\\
p_\theta(x_3=1\mid x_1=1,x_2=0)&=0.6.
\end{aligned}
\]

그러면 전체 데이터의 확률은

\[
\begin{aligned}
p_\theta(1,0,1)
&=0.8\times0.7\times0.6\\
&=0.336
\end{aligned}
\]

이다.

Log-Likelihood 역시 바로 계산할 수 있다.

\[
\begin{aligned}
\log p_\theta(1,0,1)
&=\log0.8+\log0.7+\log0.6\\
&=\log0.336.
\end{aligned}
\]

여기서는 근사적인 계산을 하지 않았다. 모델이 정의한 조건부확률들을 그대로 곱해 정확한 결합확률을 얻었다.

이것이 Autoregressive Model에서 말하는 **Exact Likelihood**의 의미다.

물론 모든 조건부분포를 효율적으로 계산할 수 있다는 가정이 필요하다. 또한 Exact라는 표현은 모델이 부여하는 확률을 정확하게 계산한다는 뜻이지, 모델이 실제 데이터 분포를 완벽하게 학습했다는 뜻은 아니다.

### Latent Variable Model과의 차이

이 성질을 1.11절에서 배운 Latent Variable Model과 비교해보자.

잠재변수 \(z\)를 이용하는 모델에서는 관측값 \(x\)의 주변확률을 다음과 같이 계산한다.

\[
p_\theta(x)
=\int p_\theta(x,z)\,\mathrm dz.
\]

여기서는 가능한 모든 잠재변수를 고려해야 하므로 적분 계산이 어려울 수 있다.

VAE에서는 이러한 문제를 다루기 위해 ELBO라는 계산 가능한 하한을 이용했다.

반면 Autoregressive Model은 결합분포를 조건부분포의 곱으로 직접 표현한다.

따라서 각 조건부분포를 계산할 수 있다면 별도의 어려운 주변화 적분 없이 \(p_\theta(x)\)를 계산할 수 있다.

이 차이가 Autoregressive Model의 중요한 장점이다.

## 2. Maximum Likelihood Estimation

이제 주어진 데이터의 Likelihood를 계산할 수 있으니, 이를 이용해 모델을 학습해보자.

실제 데이터 분포 \(p_{\mathrm{data}}\)에서 \(N\)개의 관측값을 얻었다고 하자.

\[
x^{(1)},\ldots,x^{(N)}
\overset{\mathrm{i.i.d.}}{\sim}p_{\mathrm{data}}.
\]

여기서 \(x^{(n)}\)은 \(n\)번째 관측값이며, 각 관측값은 다시 \(D\)개의 변수로 이루어져 있다.

\[
x^{(n)}
=(x_1^{(n)},\ldots,x_D^{(n)}).
\]

Maximum Likelihood Estimation(MLE)의 목표는 이 데이터들의 Likelihood를 최대화하는 모수 \(\theta\)를 찾는 것이다.

1.5절에서 배운 것처럼, 이는 평균 Negative Log-Likelihood(NLL)를 최소화하는 문제와 같다.

\[
\widehat L_{\mathrm{NLL}}(\theta)
=-\frac1N\sum_{n=1}^{N}\log p_\theta(x^{(n)}).
\]

그런데 Autoregressive Model에서는 Log-Likelihood를 조건부분포들의 합으로 표현할 수 있었다.

이를 대입하면

\[
\boxed{
\widehat L_{\mathrm{NLL}}(\theta)
=-\frac1N\sum_{n=1}^{N}
\sum_{i=1}^{D}
\log p_\theta(x_i^{(n)}\mid x_{<i}^{(n)})
}
\]

를 얻는다.

따라서 MLE는

\[
\boxed{
\widehat\theta_{\mathrm{MLE}}
\in\underset{\theta}{\arg\min}\,
\widehat L_{\mathrm{NLL}}(\theta)
}
\]

로 표현할 수 있다.

이 식이 의미하는 바는 간단하다.

각 관측값에서 앞의 변수들이 주어졌을 때 다음 변수의 실제 관측값에 높은 확률을 부여하도록 모델을 학습하는 것이다.

예를 들어 실제 데이터가 \((1,0,1)\)이라면, 첫 번째 값으로 1을, 첫 번째 값이 1일 때 두 번째 값으로 0을, 앞의 두 값이 \((1,0)\)일 때 세 번째 값으로 1을 예측할 확률이 높아지도록 학습한다.

이 과정이 모든 학습 데이터에 대해 반복된다.

여기서 한 가지 구분할 점이 있다. 관측값 \(x^{(1)},\ldots,x^{(N)}\)은 서로 i.i.d.라고 가정했지만, 하나의 관측값을 이루는 \(x_1,\ldots,x_D\)가 서로 독립일 필요는 없다. 오히려 Autoregressive Model은 변수들 사이의 의존성을 조건부분포로 표현한다.

### Forward KL과의 연결

이 학습 방식은 Chapter 1에서 배운 Forward KL과도 연결된다.

\[
\begin{aligned}
&D_{\mathrm{KL}}(p_{\mathrm{data}}\|p_\theta)\\
&=\mathbb E_{p_{\mathrm{data}}}[\log p_{\mathrm{data}}(x)]
-\mathbb E_{p_{\mathrm{data}}}[\log p_\theta(x)].
\end{aligned}
\]

여기서 첫 번째 항은 \(\theta\)와 무관하다.

따라서 Population 수준에서

\[
\boxed{
\begin{aligned}
&\underset{\theta}{\arg\min}\,
D_{\mathrm{KL}}(p_{\mathrm{data}}\|p_\theta)\\
&=\underset{\theta}{\arg\max}\,
\mathbb E_{p_{\mathrm{data}}}[\log p_\theta(x)]
\end{aligned}
}
\]

이다.

즉, Population Log-Likelihood를 최대화하는 것과 Forward KL을 최소화하는 것은 같은 최적화 문제다.

실제 학습에서는 Population의 기댓값을 직접 계산할 수 없으므로 관측 데이터의 평균으로 근사한다.

이렇게 보면 Autoregressive Model 역시 Chapter 1에서 배운 MLE의 원리를 그대로 사용하고 있다는 것을 알 수 있다.

그렇다면 실제로 신경망을 학습할 때는 어떤 Loss Function을 사용해야 할까?

그 답은 각 조건부분포를 어떤 확률분포로 표현하느냐에 따라 달라진다.

## 3. Bernoulli Conditional — Binary Cross-Entropy

먼저 각 변수가 0 또는 1의 값만 가지는 경우를 생각해보자.

\[
x_i\in\{0,1\}.
\]

예를 들어 흑백 이미지의 픽셀을 이진값으로 표현한다면 이러한 상황에 해당한다.

이때 조건부분포는 Bernoulli Distribution으로 표현할 수 있다.

앞의 변수 \(x_{<i}\)가 주어졌을 때 \(x_i=1\)이 될 확률을 다음과 같이 정의하자.

\[
\alpha_i
=p_\theta(x_i=1\mid x_{<i}).
\]

그러면 \(x_i=0\)이 될 확률은 \(1-\alpha_i\)이다.

따라서 두 경우를 하나의 식으로 표현하면

\[
\boxed{
p_\theta(x_i\mid x_{<i})
=\alpha_i^{x_i}(1-\alpha_i)^{1-x_i}
}
\]

가 된다.

처음에는 조금 복잡해 보이지만, \(x_i\)에 0과 1을 각각 대입하면 바로 이해할 수 있다.

\(x_i=1\)이면

\[
p_\theta(x_i=1\mid x_{<i})=\alpha_i
\]

이고, \(x_i=0\)이면

\[
p_\theta(x_i=0\mid x_{<i})=1-\alpha_i
\]

이다.

이제 이 조건부분포의 Negative Log-Likelihood를 계산해보자.

\[
\begin{aligned}
&-\log p_\theta(x_i\mid x_{<i})\\[4pt]
&=-\log\left[
\alpha_i^{x_i}(1-\alpha_i)^{1-x_i}
\right]\\[4pt]
&=-x_i\log\alpha_i
-(1-x_i)\log(1-\alpha_i).
\end{aligned}
\]

어디선가 본 적 있는 식이다.

\[
\boxed{
\begin{aligned}
\operatorname{BCE}(x_i,\alpha_i)
&=-x_i\log\alpha_i\\
&\quad-(1-x_i)\log(1-\alpha_i)
\end{aligned}
}
\]

바로 **Binary Cross-Entropy(BCE)** 이다.

즉, Bernoulli Conditional을 사용하는 Autoregressive Model에서는 각 변수의 NLL이 BCE와 정확히 같다.

### 간단한 예시

실제 관측값이 \(x_i=1\)이라고 하자.

모델이 \(\alpha_i=0.9\)라고 예측했다면 Loss는

\[
-\log0.9\approx0.105
\]

이다.

반면 \(\alpha_i=0.1\)이라고 예측했다면

\[
-\log0.1\approx2.303
\]

이다.

실제로 관측된 값이 1인데 모델이 그 값에 매우 낮은 확률을 부여했으므로 더 큰 페널티를 받는 것이다.

반대로 \(x_i=0\)이라면 Loss는 \(-\log(1-\alpha_i)\)가 된다. 이 경우에는 \(\alpha_i\)가 작을수록 Loss가 작아진다.

결국 BCE는 실제로 관측된 0 또는 1에 높은 확률을 부여하도록 모델을 학습시키는 함수다.

따라서 Bernoulli Conditional을 사용하는 Autoregressive Model의 전체 NLL은 각 변수의 BCE를 더한 다음, 데이터셋에 대해 평균 낸 것과 같다.

## 4. Categorical Conditional — Cross-Entropy

그런데 모든 데이터가 0과 1로만 이루어져 있는 것은 아니다.

예를 들어 이미지의 픽셀이 여러 밝기값 중 하나를 가지거나, 문장에서 다음에 등장할 토큰을 예측하는 상황을 생각해보자.

이때 각 변수는 \(K\)개의 가능한 값 중 하나를 가진다.

\[
x_i\in\{1,\ldots,K\}.
\]

이러한 변수는 Categorical Distribution으로 표현할 수 있다.

모델이 앞의 변수 \(x_{<i}\)를 입력받아 \(K\)개의 Logit을 출력한다고 하자.

\[
o_i=(o_{i,1},\ldots,o_{i,K}).
\]

Logit은 아직 확률이 아닌 실수값이다.

따라서 이를 확률로 바꾸기 위해 Softmax Function을 적용한다.

\[
\boxed{
\alpha_{i,k}
=
\frac{\exp(o_{i,k})}
{\sum_{j=1}^{K}\exp(o_{i,j})}
}
\]

이렇게 계산한 \(\alpha_{i,k}\)는 \(x_i=k\)일 조건부확률이다.

\[
p_\theta(x_i=k\mid x_{<i})=\alpha_{i,k}.
\]

Softmax를 적용했으므로 각 확률은 음수가 아니며, 모든 범주에 대한 확률의 합은 1이 된다.

\[
\sum_{k=1}^{K}\alpha_{i,k}=1.
\]

이제 실제 관측값이 \(x_i=k^*\)라고 하자.

모델은 여러 범주에 확률을 부여했지만, 우리가 실제로 관측한 값은 \(k^*\) 하나다.

따라서 해당 조건부분포의 NLL은

\[
\boxed{
-\log p_\theta(x_i=k^*\mid x_{<i})
=-\log\alpha_{i,k^*}
}
\]

가 된다.

이 식을 One-hot Vector를 이용해 표현할 수도 있다.

실제로 관측한 범주가 \(k^*\)일 때

\[
y_{i,k}
=
\begin{cases}
1,&k=k^*,\\
0,&k\neq k^*
\end{cases}
\]

라고 정의하자.

그러면

\[
\boxed{
\operatorname{CE}(y_i,\alpha_i)
=
-\sum_{k=1}^{K}y_{i,k}\log\alpha_{i,k}
}
\]

이다.

One-hot Vector에서는 실제 범주에 해당하는 성분만 1이므로, 결국 이 식은 \(-\log\alpha_{i,k^*}\)와 같다.

즉, **Categorical Conditional의 NLL은 Categorical Cross-Entropy와 정확히 같다.**

### 간단한 예시

다음 토큰이 세 가지 후보 중 하나라고 생각해보자.

모델이 예측한 확률이

\[
\alpha_i=(0.1,0.7,0.2)
\]

라고 하자.

그런데 실제 정답이 세 번째 토큰이었다면 One-hot Vector는

\[
y_i=(0,0,1)
\]

이다.

따라서 Cross-Entropy는

\[
\begin{aligned}
\operatorname{CE}(y_i,\alpha_i)
&=-(0\log0.1+0\log0.7\\
&\qquad+1\log0.2)\\[4pt]
&=-\log0.2\\[4pt]
&\approx1.609.
\end{aligned}
\]

모델이 실제 정답에 부여한 확률이 0.2였기 때문에 비교적 큰 Loss가 발생한 것이다.

만약 실제 정답에 0.9의 확률을 부여했다면 Loss는 \(-\log0.9\approx0.105\)로 훨씬 작아졌을 것이다.

결국 Categorical Cross-Entropy 역시 실제 관측된 값에 높은 확률을 부여하도록 모델을 학습시키는 함수다.

## Autoregressive Model의 Loss 정리

지금까지의 내용을 정리해보자.

Autoregressive Model에서는 결합분포를 조건부분포의 곱으로 표현한다.

\[
p_\theta(x)
=\prod_{i=1}^{D}p_\theta(x_i\mid x_{<i}).
\]

따라서 전체 데이터의 Negative Log-Likelihood는

\[
-\log p_\theta(x)
=
-\sum_{i=1}^{D}
\log p_\theta(x_i\mid x_{<i})
\]

이다.

각 조건부분포를 Bernoulli Distribution으로 표현한다면 해당 항은 BCE가 되고, Categorical Distribution으로 표현한다면 Categorical Cross-Entropy가 된다.

| 조건부분포 | 변수의 형태 | NLL |
|---|---|---|
| Bernoulli | \(x_i\in\{0,1\}\) | Binary Cross-Entropy |
| Categorical | \(x_i\in\{1,\ldots,K\}\) | Categorical Cross-Entropy |

따라서 BCE와 Categorical Cross-Entropy는 단순히 신경망에서 관습적으로 사용하는 Loss Function이 아니다.

**각 조건부분포에 대한 Negative Log-Likelihood를 계산한 결과가 바로 이러한 Cross-Entropy Loss인 것이다.**

이 관계를 이해하면 데이터의 형태에 따라 왜 서로 다른 Loss Function을 사용하는지도 자연스럽게 설명할 수 있다.

---

이번 절에서는 Autoregressive Model이 주어진 데이터의 Likelihood를 어떻게 계산하고, 이를 이용해 학습하는지 살펴봤다.

조건부분포를 정확하게 계산할 수 있다면 전체 결합확률도 정확하게 계산할 수 있고, MLE를 통해 모델의 모수를 학습할 수 있다.

이때 조건부분포가 Bernoulli인지 Categorical인지에 따라 NLL은 각각 Binary Cross-Entropy와 Categorical Cross-Entropy의 형태로 나타난다.

지금까지는 주어진 데이터 \(x\)의 확률을 계산하고 학습하는 방법을 살펴봤다.

그렇다면 학습한 분포에서 새로운 데이터를 생성하려면 어떻게 해야 할까?

다음 절에서는 조건부분포를 순서대로 이용해 새로운 데이터를 생성하는 **Ancestral Sampling**을 살펴본다.
