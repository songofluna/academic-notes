# 생성모델 노트의 글쓰기 기준

기준 자료는 `content/notes/newnote1.md`(현재 §§1.1–1.2), `docs/publishing/README.md`, 그리고 사용자의 “미적분학과 기초 확률을 배운 통계학과 1학년이 따라갈 수 있는 쉬운 학술 문체” 요청이다. 과거 대화의 보이지 않는 문장을 복원한 가이드가 아니다. 원본의 논리 순서와 수학 내용을 먼저 보존하고 이 설명 방식을 적용한다.

## 설명이 이어지는 방식

`newnote1`의 “데이터의 분포를 학습한다는 것”은 키의 분포라는 익숙한 상황에서 출발해 관측 데이터와 알 수 없는 실제 분포를 구분한다. 그다음 `p_data`, `p_theta`, 모수, 학습 목적을 차례로 도입한다. 새 개념을 읽는 데 필요한 말을 먼저 제공한다는 점이 핵심이다. 모든 절에 일상 비유를 새로 붙이라는 뜻은 아니다. 원본의 예제가 있으면 그것을 우선하고, 없는 예제는 설명에 꼭 필요할 때만 근거와 역할을 검토한다.

수식을 쓰기 전에 무엇을 계산하려는지 설명한다. 수식 뒤에는 새 기호의 의미, 계산의 결과가 말해 주는 것, 다음 단계로 넘어가는 이유를 문장으로 연결한다. `argmin`을 “함수의 값을 가장 작게 만드는 입력값”으로 풀어쓴 부분, 기댓값을 “분포에 따라 가중평균”으로 설명한 부분처럼 정의와 일상 언어가 연결되어야 한다.

한 문단에는 한 논점을 둔다. 문장이 길어져 여러 전제와 결론이 한꺼번에 들어가면 나누되, 모든 문장을 별도 문단으로 쪼개지 않는다. “여기서 x는 …이다”, “따라서 …로 계산할 수 있다”처럼 필요한 연결은 쓰되 매 수식마다 같은 문구를 반복하지 않는다. 질문형 소제목은 실제로 해결할 질문이 있을 때만 쓴다.

## 수학의 깊이를 유지하는 방법

쉽게 쓰는 것은 수학을 줄이는 일이 아니다. 원본의 수식, 조건, 정의역, 적분·합의 범위, 인덱스, 차원, 정규화 상수, 부호, 등호와 근사 기호를 모두 보존한다. 각 변형에서 사용한 미적분·확률 법칙을 짧게 설명하고, 생략된 계산 때문에 첫 독자가 따라갈 수 없다면 필요한 중간 단계만 추가한다. 추가 유도는 `review.json`의 reasoning에 근거를 남긴다.

`newnote1`이 확률과 확률밀도를 구분하고, 좌표 `x_j`와 관측값 `x^(i)`를 구분하는 방식처럼 혼동의 원인이 되는 표기를 명시한다. 가정 없이 항상 성립하는 정리처럼 서술하지 않는다. 원본끼리 표기가 다르면 대응 관계를 기록하고, 수학적으로 충돌하면 검토 대상으로 남긴다. 필기에서 읽히지 않는 첨자나 부호를 문맥상 그럴듯하다는 이유로 확정하지 않는다.

문체 참고 글도 수식의 권위 있는 원본은 아니다. 현재 `newnote1`에는 분포족의 집합 괄호, 일부 aligned/행렬의 줄 구분, divergence의 인자 구분처럼 원본 대조가 필요한 표현이 있다. 이 자동화에서는 기존 글을 수정하지 않으며 그 표기를 새 글에 복제하지 않는다. 해당 내용이 새 절에 필요하면 제공된 원본에서 확인한다.

## 용어와 어조

설명은 자연스러운 한국어 평서문으로 쓴다. 확률분포, 기댓값, 모수, 정규분포처럼 정착된 한국어 통계 용어를 유지한다. 처음 필요할 때 확률분포(Probability Distribution), 모수(Parameter)처럼 영어를 병기한다. Density Evaluation, Sampling, Pushforward, Jacobian Determinant, Normalizing Flow 등은 기존 노트와 같은 용어를 사용한다. 자연스러운 “밀도를 계산한다”까지 모두 영어로 바꾸지는 않는다.

“아주 쉽다”, “걱정하지 말자” 같은 안심 문구, 과장, 광고 문구, 지어낸 개인 경험은 넣지 않는다. 굵은 글씨는 독자가 놓치면 다음 설명을 이해하기 어려운 개념에 제한한다. 긴 요약 목록과 상투적인 결론으로 글을 늘리지 않는다. 원본에 있는 중요한 비교는 짧은 표로 보여줄 수 있다.

## 길이와 구성

원본 Section 번호·제목·예제·논리 순서를 유지한다. 작은 절은 의미 있는 소제목 두세 개로 충분할 수 있다. 원본 밀도에 비해 글이 길어지면 연결에 꼭 필요한 설명인지 다시 판단한다. 기존 집필 지침의 반 페이지 800–1,500자, 한 페이지 1,500–3,000자, 두 페이지 3,000–5,000자는 분량을 채우는 목표가 아니다. 수학 누락 없이 설명하려면 초과가 필요한 경우 이유를 기록한다.

`compare`의 proseCharacters는 frontmatter·공백·제목·코드·수식·이미지/데모 줄을 제외한 문자 수다. 강조 기호, 표, 캡션 등은 남으므로 순수 한글 음절 수가 아니다. 숫자만으로 난이도나 충실도를 평가하지 않는다.

## 집필 뒤 다시 읽기

원본의 모든 중요한 항목을 실제 본문 구절에 연결하고 다음을 확인한다: 처음 나오는 기호를 설명했는가, 식 사이의 변형을 따라갈 수 있는가, 원본의 조건과 예제를 빠뜨리지 않았는가, 출처 없는 주장이나 과도한 보충이 없는가, 문단 사이에서 왜 다음 내용이 필요한지 드러나는가. 그림과 인터랙티브를 제거해도 본문이 논리적으로 완결되어야 한다.
