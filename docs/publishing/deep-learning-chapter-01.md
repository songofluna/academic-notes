## Interactive decisions

Three compact code-native components serve distinct purposes. Mathematical explanations remain in the surrounding ChatGPT manuscript. They use the existing lazy iframe and portable-preview infrastructure, keyboard-operable controls, and source-specific numeric examples.

- **1.5 `[demo:dl-activations]`**: identity, the source unit step `1{z>0}`, sigmoid, tanh, ReLU and Leaky ReLU. Input, output and local slope are shown together. Step/ReLU/Leaky ReLU report an undefined mathematical derivative at zero; the step's chosen value `g(0)=0` is separate from differentiability. The discontinuous step is drawn with two separate horizontal segments and the correct open/closed endpoints. Softmax stays in the vector-valued prose and is not misrepresented as a scalar control.
- **1.6 `[demo:dl-xor]`**: source model `h1=ReLU(x1+x2)`, `h2=ReLU(x1+x2−1)`, score `h1−2h2`, threshold 0.5. The four binary inputs can be selected, and the user can switch input/hidden views or remove ReLU while keeping all weights fixed. Both positive inputs are explicitly labeled at their shared hidden point `(1,0)`. Removing ReLU gives `2−x1−x2` and misclassifies `(0,0)`. This is an untrained fixed construction; the score is not called a calibrated probability.
- **1.10 `[demo:dl-forward]`**: the exact source's 2→3→1 network with 13 fixed parameters. Its default input `(2,−1)` gives `z1=(3,0,−2.5)`, `a1=(3,0,0)`, output logit 1.4 and sigmoid probability 0.8021838886. Input sliders and four computation stages expose the same affine/ReLU/readout/sigmoid calculations. No gradient, parameter update or training simulation is introduced.
