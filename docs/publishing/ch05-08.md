## Interactive

Embed `[demo:gated-pixelcnn-stacks]` on its own line. Standalone: `demos/gated-pixelcnn-stacks.html`. The existing lazy iframe loader, frame-source-checked resizing and portable preview packer support it.

**Context** shows the theoretical partition of all allowed raw inputs: all preceding rows, plus earlier columns in the target row. It is explicitly labeled Theoretical context. It is not a finite-depth receptive-field simulator and has no depth control.

**Shift Down** uses a concrete example, not a claim about all Gated PixelCNN implementations. Its top-aligned 2×3 convolution at (r,c) reads rows r−1,r and columns c−1,c,c+1, with zero padding. Without shifting it contains the current pixel and, except at the right edge, a future pixel. After shifting, Ṽ(r,c)=V(r−1,c), and the first output row is zero. These raw inputs belong only to earlier rows. The horizontal raw-input kernel is 1×3 with a strict-left Mask A (only c−1). Their union is the final example input set. Pointwise gates, 1×1 channel mixing and a causal hidden residual do not expand spatial dependency sets.

At the default target m=(3,3), unshifted raw inputs are g,h,i,l,m,n. Shifted inputs are b,c,d,g,h,i. Adding the horizontal input l yields seven strictly past inputs. The theoretical panel has 10 vertical + 2 horizontal = 12 allowed past inputs. This difference is intentional.

Validation includes independent positive-weight forward impulse convolutions, an actual zero-padded array shift and horizontal convolution on grids of sizes 1–8, for every source and every target. Current/future raw inputs never enter the final shifted output; top-row vertical inputs are empty. Browser QA covers mode/target/reset, boundaries, map direction, zero row, mobile layout, math, figures and lazy iframe sizing.
